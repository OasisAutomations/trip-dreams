# Trip Dreams

Family trip planner: a map of dream trips, cost estimates, a savings goal per trip (per-week and per-paycheck amounts), kid-friendly checklists, and a memory wall for finished trips.

Runs entirely in the browser. Trips are stored only on the device (IndexedDB). No accounts, no analytics. Backup/restore uses a local JSON file.
Network use: map tiles from tile.openstreetmap.org and place search via Nominatim (only the search words / tapped coordinates are sent).

Vendored: Leaflet 1.9.4 (BSD-2-Clause).
